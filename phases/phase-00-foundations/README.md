# Fase 0 — Fundamentos previos (opcional)

**Estado:** opcional. Puedes saltarla si ya dominas los fundamentos; utiliza el [test de nivel inicial](../../templates/initial-level-assessment.md) para decidir. Esta fase no suma ni modifica las 90 sesiones principales.

## Objetivo

Asegurar una base mínima para comprender ejemplos de red y datos. No es una fase de administración de infraestructura ni de configuración avanzada.

## Sesiones opcionales (5–6)

Cada sesión conserva la estructura 10/20/35/15/10 minutos: recuperación, explicación, práctica guiada, ejercicio individual y evidencia/reflexión.

| Sesión | Tema | Práctica | Evidencia de datos |
|---|---|---|---|
| 0.1 | Redes básicas: IP, puertos y TCP/UDP | Clasificar ejemplos ficticios de direcciones, puertos y protocolos | Tabla de IP/puerto/protocolo y explicación |
| 0.2 | Lógica de datos: tabla, clave y registro | Diseñar una tabla pequeña e identificar clave primaria y registros | Tabla de ejemplo y diccionario de campos |
| 0.3 | Terminal básica | Navegar carpetas, listar archivos y leer un CSV local | Tabla con nombre, extensión y tamaño de archivos de práctica |
| 0.4 | Lectura de JSON | Identificar objetos, arrays, claves, tipos y valores | JSON anotado y tabla de campos |
| 0.5 | Lectura de HTML | Reconocer etiquetas, atributos y estructura de una página de ejemplo | Tabla de etiquetas/atributos y su significado |
| 0.6 | Integración (opcional) | Relacionar una solicitud web ficticia con su respuesta JSON/HTML y una tabla de eventos | Diagrama de flujo y tabla resumen |

## Regla para omitir

- Si el test inicial alcanza el umbral de Fase 0, puedes omitir estas sesiones.
- Si no alcanza el umbral, completa solo los temas que fallaste; no necesitas repetir lo que ya demostraste.
- La Fase 0 es preparatoria y no cuenta dentro de las 90 sesiones.
