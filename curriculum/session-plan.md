# Plan detallado de sesiones — Security Data Analyst

Cada sesión dura 90 minutos. Sigue la estructura general del [diseño operativo](README.md). Las prácticas usan datos sintéticos y entornos propios/autorizados. No avances si no puedes explicar el resultado.

## Criterio general de aprobación

Cada sesión requiere: (1) explicación con palabras propias, (2) práctica realizada, (3) evidencia verificable y (4) preguntas de razonamiento. Si una parte no se completa, se registra como pendiente. No se inventan resultados ni se marca como aprobado por haber leído el material.
