# Ruta de aprendizaje — Security Data Analyst

## Diseño operativo

- **Carga principal:** 90 sesiones de aprendizaje.
- **Preparación:** 3 sesiones previas, separadas del avance académico.
- **Ritmo:** lunes a sábado, 08:00–09:30, zona horaria `America/Tegucigalpa`.
- **Duración estimada:** 15 semanas de aprendizaje (90 sesiones) más 3 sesiones de preparación; aproximadamente 16 semanas calendario, según la fecha de inicio y cualquier pausa.
- **Carga académica principal:** 135 horas; preparación adicional: hasta 4.5 horas.
- **Regla de avance:** una sesión no se considera aprobada hasta completar práctica, evidencia y evaluación.

## Estructura de cada sesión de 90 minutos

1. 10 min — recuperación activa: explicar sin consultar apuntes lo aprendido anteriormente.
2. 20 min — explicación guiada y lectura de la fuente indicada.
3. 35 min — práctica paso a paso con datos sintéticos o recursos autorizados.
4. 15 min — ejercicio individual y comprobación del resultado.
5. 10 min — evidencia, reflexión y registro de dudas.

Si la instalación o una dificultad técnica consume tiempo, no se recorta la práctica para aparentar que la sesión terminó. Se registra el bloqueo y se retoma.

## Preparación del entorno (no cuenta dentro de las 90 sesiones)

| Preparación | Resultado esperado | Criterio para darla por lista |
|---|---|---|
| P1 — Inventario y organización | Verificar qué herramientas ya existen en el Mac; crear estructura de trabajo y revisar accesos a GitHub. | No instalar duplicados; carpeta y repositorio identificados. |
| P2 — Herramientas base | Verificar Python, editor, Git, navegador y cliente SQLite; instalar solo lo que falte. | Versiones comprobadas y prueba mínima ejecutada. |
| P3 — Accesos y entorno de práctica | Revisar acceso a Google Calendar, GitHub Actions y recursos de aprendizaje; preparar datos sintéticos. | Prueba local reproducible; secretos fuera del repositorio. |

**Compatibilidad importante:** Power BI Desktop requiere Windows. Se utilizará un entorno Windows virtualizado en el Mac. La preparación P3 deberá comprobar que Power BI Desktop se instala y ejecuta correctamente, que el rendimiento permite trabajar con los archivos del curso y que se dispone de la licencia/cuenta necesaria para las funciones que se practicarán. No se dará por resuelto hasta completar esa prueba.

## Fuentes de referencia

Se priorizan documentación oficial y material educativo reconocido: MDN, SQLBolt, documentación de Python, SQLite, OWASP, Microsoft Learn, documentación de Google y NIST. Se usarán solo las secciones relacionadas con el objetivo de cada sesión. Los enlaces no sustituyen la explicación guiada ni la práctica.

## Límites y seguridad

- Solo datos sintéticos, públicos o cuyo uso esté expresamente autorizado.
- No introducir credenciales, cookies, tokens, datos personales ni información laboral confidencial en ejercicios.
- No ejecutar pruebas de seguridad contra sistemas de terceros.
- Diferenciar siempre entre conceptos, ejercicios simulados y controles realmente implementados.
- La ruta desarrolla fundamentos y evidencia práctica; no equivale a certificación ni garantiza por sí sola un puesto laboral.
