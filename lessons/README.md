# Lecciones diarias

Las lecciones se desarrollan progresivamente a partir del tracker y de las guías de fase. No se crean 90 documentos vacíos: cada lección debe incluir explicación, práctica, evidencia y criterios de evaluación útiles.

## Lección desarrollada

## Plantilla

Usa [TEMPLATE.md](TEMPLATE.md) para nuevas lecciones. Antes de crear una lección, verifica que sus objetivos, práctica y evidencia coincidan con el día correspondiente en [tracker.md](../tracker.md).

## Regla de avance

Una lección puede marcarse como aprobada únicamente después de completar la práctica, entregar evidencia y superar la evaluación. La existencia de un archivo no significa que la sesión esté completada.
